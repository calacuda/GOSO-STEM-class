# GOSO-STEM-class

Welcome GOSO STEM students!

This Repository contains the materials for the course, along with notes from the lessons. The lessons are taught live at GOSO one Wednesdays and Thursdays from 2pm to 4pm over the summer of 2025.

## Directory Structure

| **Directory** | **Whats Inside** |
| ------------- | ---------------- |
| `/arduino-config/` | Files on who to set up the Arduino IDE (v2) to work with the AlgoC platform. |
| `/commands-and-code-samples/` | Contains Arduino source code files which; explain the different AlgoC commands and/or explain c/c++ syntax and programming concepts. |
| `important-links.md` | Contains links to the Arduino IDE download site, and and Board package link that is needed to add the AlgoC board to the Arduino IDE. |
